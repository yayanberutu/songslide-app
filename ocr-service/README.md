# OCR Service

This directory will contain the optional Python FastAPI OCR service skeleton.

Planned responsibilities:

- Expose a lightweight health endpoint.
- Provide a disabled/not-implemented OCR endpoint in the MVP.
- Keep OpenCV, PaddleOCR, model downloads, and other heavy OCR dependencies optional.

OCR is disabled by default and must not be required for local development on a MacBook Pro 2017.

Runtime implementation is intentionally not included in this scaffold phase.
