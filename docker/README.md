# Docker

This directory will contain Docker and Docker Compose support files.

Planned responsibilities:

- Local PostgreSQL runtime.
- Backend, frontend, and export service compose wiring.
- Persistent volumes for PostgreSQL and local file storage.
- Optional OCR service profile.

OCR must remain disabled by default so local development stays practical on a MacBook Pro 2017.

Docker Compose implementation is intentionally not included in this scaffold phase.
