# Frontend

This directory will contain the Next.js, React, TypeScript, and Tailwind CSS operator UI.

Planned responsibilities:

- Manage song books and songs.
- Upload source notation images.
- Provide a visual line-based editor backed by `song_arrangements.content_json`.
- Preview selected verses with refrain handling.
- Trigger PPTX and PNG exports.

Operators should not edit raw JSON directly. Full Next.js scaffolding is intentionally not included in this scaffold phase.
